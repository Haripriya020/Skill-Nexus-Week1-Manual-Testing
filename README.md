# Skill Nexus Week 1 – Manual Testing

## Project
Manual testing of the OrangeHRM web application.

## Objective
To perform complete manual testing of a sample web application by creating and executing 30+ test cases and documenting identified defects.

## Testing Performed
- Functional Testing
- Smoke Testing
- Positive Testing
- Negative Testing
- Validation Testing
- Search and Filter Testing
- Data Persistence Testing
- Navigation Testing
- Basic Session Testing

## Deliverables
- Test Plan
- 32 Test Cases and Execution Results
- Bug Report
- Bug Evidence Screenshots

## Application Under Test
OrangeHRM Demo Web Application

## Defect Summary
One reproducible validation defect was identified and documented with screenshot evidence.
